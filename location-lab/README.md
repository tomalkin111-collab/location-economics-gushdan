# מעבדת מיקום | תום מלכין

אפליקציה בעברית המבוססת על פרויקט הגמר בכלכלת מיקום. כוללת 88 אזורי תעסוקה, מפה אמיתית, דירוגי נגישות ותרחישים אינטראקטיביים.

## פרסום ב־GitHub Pages — ללא התקנה

1. חלצו את ZIP.
2. צרו repository חדש ב־GitHub, למשל `location-lab`. עבור GitHub Free בחרו Public אם ברצונכם להשתמש ב־Pages בחינם.
3. העלו את **תוכן תיקיית location-lab** לשורש המאגר. הקובץ `index.html` צריך להיות בשורש, ולא בתוך תיקייה נוספת. אל תעלו רק את ZIP.
4. ב־Settings → Pages בחרו **Deploy from a branch**.
5. בחרו את הענף `main` ואת התיקייה `/(root)` ולחצו Save.
6. בסיום הפרסום יופיע הקישור לאתר במסך Pages. שמרו אותו כתוספת להגשה.

אין צורך בפקודת Build, ב־npm, במסד נתונים או במפתח API. הקבצים משתמשים בנתיבים יחסיים ולכן עובדים גם כשהאתר מתפרסם תחת שם המאגר.

תיעוד: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## איך משתמשים

- בוחרים אזור במפה או בטבלת הדירוג. בחירה חדשה מאפסת את תוספת התחנות בלבד.
- משנים את משקל האוכלוסייה, רגישות המרחק וטווח ספירת התחנות.
- מוסיפים תחנות באזור הנבחר כדי לבדוק תרחיש. אין כאן תכנון של מיקום פיזי לתחנות חדשות.
- משתמשים ב־+ ו־− לזום או גוררים את המפה. גלילת העמוד אינה משנה את זום המפה.
- כפתור המיקוד חוזר לאזור הנבחר; כפתור כל האזורים מציג את כלל מרחב הבדיקה.
- הטאבים הנוספים מסבירים את המחקר ואת שיטת החישוב.

## קבצים

- `index.html` — התוכן והמבנה.
- `style.css` — העיצוב והתאמה לנייד.
- `app.js` — חישובי המדדים, התרחישים, הטבלה ומפת הנתונים החלופית.
- `map.js` — מפת הרחובות, המרת קואורדינטות ואינטראקציות המפה.
- `data.js` — נתוני הפרויקט וגבולות 88 אזורי התעסוקה.
- `tests/model.test.cjs` — בדיקת התאמה לנתוני המקור ומבחני תרחישים.
- `.nojekyll` — מסמן ל־GitHub Pages לשרת את האתר כקבצים סטטיים.

## מפה ונתונים

מפת הרקע: OpenStreetMap, באמצעות Leaflet 1.9.4. המרת קואורדינטות: Proj4js 2.11.0, מ־EPSG:2039 ל־WGS84. הגאומטריה נשמרת בנתוני המקור ומומרת בדפדפן פעם אחת בעת טעינת המפה.

הספריות נטענות מ־unpkg ומפת הרקע משרתי OpenStreetMap, ולכן המפה דורשת חיבור לאינטרנט. לא מתבצעים איסוף מיקום המשתמש, שמירה בשרת, הורדה מרוכזת או טעינה מוקדמת של אריחי מפה. דפדפן רגיל מנהל את מטמון האריחים. הקרדיט מוצג על המפה.

אם שירות חיצוני אינו נטען, מוצגת הודעה ומפת הנתונים/הטבלה נשארות זמינות. אין הבטחת זמינות של ספק המפה. האתר מיועד להדגמה אקדמית בהיקף קטן. לשימוש מסחרי או תעבורה גבוהה יש לבחור ספק אריחים מתאים ולעדכן את הכתובת והקרדיט ב־map.js בהתאם לתנאיו.

- Leaflet: https://leafletjs.com/examples/quick-start/
- Proj4js: https://proj4js.org/
- מערכת קואורדינטות: https://epsg.io/2039
- מדיניות אריחים: https://operations.osmfoundation.org/policies/tiles/
- קרדיט ורישיון המפה: https://www.openstreetmap.org/copyright

## משמעות התוצאות

ציוני הבסיס תואמים לקובץ `gush_dan_employment_accessibility_results.csv` מהפרויקט. מדד ברירת המחדל משלב 70% נגישות לאוכלוסייה ו־30% ספירת תחנות בטווח 500 מטר.

זהו מדד נגישות יחסי, ולא מודל בחירת פירמות שנאמד בישראל. המערכת אינה כוללת מחירי שכירות, זמן נסיעה אמיתי, תדירות שירות או בחירות מיקום של פירמות. שינוי ברקע המפה אינו מעדכן את נתוני המחקר. מקור הנתונים וההנחות מפורטים באתר.

לא כל מרכז משרדים בגוש דן נכלל בשכבת אזורי התעסוקה; אין להסיק מהדירוג על חלופות שלא נכללו. שמות הרשויות נשמרו כפי שהופיעו בקובץ, כולל תוויות שדורשות בדיקה במקור.

## בדיקות

אם מותקן Node.js, מתוך שורש המאגר אפשר להריץ:

```sh
node tests/model.test.cjs
```

הבדיקה אינה דורשת חבילות נוספות. היא משווה את כל 88 ציוני ברירת המחדל לעמודת התוצאות המקורית, בודקת 12 צירופי משקל ורגישות, קלט לא תקין ותרחיש הוספת תחנות. זו בדיקת חישוב ולוגיקת מסך עם סביבת DOM מדומה, ולא בדיקת דפדפן מלאה.

לפני ההגשה, לאחר הפרסום, בדקו בדפדפן:

1. מופיעים רחובות וקרדיט OpenStreetMap; ללא הודעת שגיאה במפה.
2. קרית אריה מקבלת בברירת המחדל ציון 91.4 ודירוג ראשון.
3. בחירת רמת סיב ממקדת אותה; תוספת 50 תחנות נותנת כ־95.8 ומקום ראשון.
4. שינוי משקל/טווח/רגישות משנה את הציונים בלי להזיז את המפה.
5. חיפוש, שלושת הטאבים, איפוס וזום עובדים גם בנייד.

בדיקות החישוב ותחביר JavaScript בוצעו בעת ההכנה. טעינת הרקע והעיצוב בדפדפן חי לא אומתו בסביבה זו עקב מגבלות הגישה. אין בקוד או בחבילה מפתחות, הרשאות או פרטי חיבור ל־Sites.
